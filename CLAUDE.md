# Claude Code — Instructions for This Repo

The canonical instructions for how to review code in this repo live in
**`AGENTS.md`** at the repository root. Read it in full before doing any
code review work here, and follow it exactly — it covers review scope,
feedback format, when to make fixes directly vs. explain first, the
end-of-session commenting pass, and the review-summary output format.

This file exists only so Claude Code (which looks for `CLAUDE.md`
specifically) knows where to find those instructions. There is nothing
Claude-Code-only to add beyond that — if a genuinely Claude-Code-specific
behavior needs to be documented later, add it below this line.
